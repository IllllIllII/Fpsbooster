# Frame Booster

윈도우 게임용 프레임 부스터 (단일 exe, 설치 없음)

- 게임 전 백그라운드 앱 정리, 게임 끝나면 자동 복원
- 실시간 FPS · 1% Low · 프레임타임 · PC 레이턴시 · Present Mode 측정 (Intel PresentMon, MIT)
- 게임 오버레이 (간단히 / 기본 / 자세히)
- 플레이 기록 그래프 분석 · 부스트 전후 비교
- 전원 모드 슬라이더 (X3D는 균형 조정 권장)

## 다운로드
[Releases](https://github.com/IllllIllII/Fpsbooster/releases)에서 `FrameBooster.exe`를 받아 실행하세요.
사용법은 `사용법.txt`, 변경 내역은 `패치노트.txt`를 보세요.

## 빌드
`build/build.bat` (Windows, llvm-mingw) 또는 `build/build.sh` (Linux 크로스 빌드)
