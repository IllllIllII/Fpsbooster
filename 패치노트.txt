Frame Booster v3.1.2 패치노트

[버그 수정]
- 게임을 꺼도 실시간 프레임에 계속 "측정 중"으로 남던 문제 (게임 종료 2초 뒤 측정 정리 + 기록 저장)
- 새 프레임이 없을 때 마지막 프레임타임 값이 그대로 남던 표시
- 게임 모드 토글이 윈도우 실제 설정과 따로 놀던 문제 (이제 윈도우 설정 > 게임 모드와 같은 값을 켜고 끔)

Frame Booster v3.1.1 패치노트

[버그 수정]
- 측정 도구가 실행되지 않을 때 1초마다 계속 다시 실행하던 문제 → 잠시 쉬었다가 재시도, 원인 표시
- 측정 대상 게임이 바뀔 때 게임이 안 꺼졌는데 앱이 자동 복원되던 문제
- 끌 앱이 없으면 BOOST를 눌러도 켜짐 상태가 안 되던 문제
- 목록을 띄운 뒤 직접 끈 앱이 게임 끝나고 다시 켜지던 문제
- 게임 중간에 부스트를 켜거나 끈 기록이 잘못 표시되던 문제
- 윈도우 시작 시 실행: 폴더 이름에 특수문자가 있으면 관리자 실행 등록이 안 되던 문제
- 효과 비교에 "-0.0%"로 나오던 표시

[개선]
- 오버레이 갱신 0.5초로 (숫자 읽기 쉽게, 부담 절반)
- 앱 전체 용량 100MB 제한 (넘으면 오래된 플레이 기록부터 자동 삭제)
- 작업 기록 파일이 계속 커지지 않게 정리

Frame Booster v3.0

[새 기능]
- 대시보드 화면으로 새 디자인
- 실시간 프레임 측정: FPS · 1% Low · 프레임타임 · Present Mode
- 게임 오버레이: 간단히 / 기본 / 자세히, 위치 9칸 + 직접 옮기기
- 프레임 분석: 게임 끝나면 기록 저장, 그래프 확대·이동, 기록끼리 비교
- 부스트 효과: 부스트 켰을 때 / 껐을 때 FPS · 1% Low 비교
- 전원 모드 슬라이더: 균형 조정 / 고성능 / 최고의 성능 (X3D는 균형 권장)
- 내 PC 사양에 맞춰 저사양 / 고사양 효과 표시

[변경]
- 윈도우 설정 최적화는 효과가 확인된 2개만 (게임 녹화 끄기, 게임 모드)
- 마우스 가속 등 나머지 윈도우 설정은 건드리지 않음
- 이전 버전에서 바꾼 설정은 [원래대로] 버튼으로 되돌리기
- 새 아이콘

[개선]
- 게임 측정 중에는 앱 자체 우선순위를 낮춰 프레임 영향 최소화
- 파일 크기 0.6MB
