Frame Booster v3.1.2 사용법
================================

■ 실행
  FrameBooster.exe 하나만 실행하면 됩니다. (설치 필요 없음)
  설정·기록은 exe와 같은 폴더(data 폴더 포함)에 저장됩니다.

■ 대시보드
  · BOOST 버튼 : 체크된 앱을 끄고 게임할 준비. 게임이 끝나면 자동으로 다시 켜요.
  · 실시간 프레임 : FPS · 1% Low · 프레임타임 · PC 레이턴시 · Present Mode
  · 부스트 효과 : 같은 게임의 "부스트 없이" 기록과 "부스트" 기록을 비교
  · 전원 모드 : 슬라이더를 끌어서 균형 조정 / 고성능 / 최고의 성능
                (부스트하는 동안만 적용, 끝나면 원래대로. X3D CPU는 균형 조정 권장)

■ PC 레이턴시
  · NVIDIA Reflex를 지원하는 게임(오버워치2 등)은 "PC 레이턴시"로 표시
    (입력 → 화면 표시까지, NVIDIA FrameView의 PC Latency와 같은 방식)
  · 지원하지 않는 게임(배그 등)은 "렌더 지연"(프레임 시작 → 화면 표시, 추정값)으로 표시

■ 부스트
  · 체크 = 부스트할 때 끔 / 체크 해제 = 유지 (다음에도 기억)
  · 디스코드, 게임 런처, 안티치트, 그래픽 드라이버는 기본으로 유지
  · 오른쪽은 효과가 확인된 항목만 (저사양/고사양 PC별 영향 표시)

■ 프레임 측정 · 분석
  · 프레임 측정은 관리자 권한이 필요해요. → [관리자로 다시 시작] 한 번
    (관리자로 실행한 상태에서 "윈도우 시작 시 실행"을 켜두면 다음부터 자동으로 관리자 실행)
  · 처음 한 번 측정 도구(Intel PresentMon, 약 1MB)를 받아요.
  · 감시 게임 또는 전체 화면 게임을 켜면 자동으로 측정, 20초 이상 플레이하면 기록 저장
    (앱 전체 100MB 안에서 최신 기록부터 보관, 넘으면 오래된 기록 자동 삭제)
  · 프레임 분석 : 기록 선택 → 프레임타임 / FPS / 레이턴시 그래프
                  휠로 확대, 드래그로 이동, 더블클릭으로 전체
                  다른 기록에 마우스를 올려 [비교]를 누르면 두 기록을 겹쳐서 비교

■ 오버레이
  · 설정에서 켜기 → 간단히(FPS만) / 기본 / 자세히
  · 위치는 9칸 중 선택하거나 [직접 옮기기]로 끌어서 이동
  · 게임에 코드를 넣지 않는 바깥 창이라 안티치트에 안전해요.

■ 트레이
  · X 버튼을 눌러도 트레이에서 계속 실행됩니다.
  · 트레이 아이콘 우클릭 → 부스트 / 해제 / 오버레이 / 종료

■ 업데이트
  · 새 버전이 나오면 왼쪽 아래에 "업데이트" 표시 → 누르고 [지금 업데이트]
  · 설정과 기록은 그대로 유지됩니다.

■ 참고
  · 마우스 가속 등 윈도우 설정은 건드리지 않아요.
  · 이전 버전에서 바꾼 윈도우 설정이 있으면 부스트 탭 아래 [원래대로]로 되돌릴 수 있어요.
  · 윈도우 SmartScreen 경고가 뜨면 "추가 정보 → 실행"
